HOW TO APPLY THIS UPDATE
  1. Unzip this somewhere temporary.
  2. Copy index.html into your original site folder, overwriting the old one.
  3. Copy everything inside this assets/ folder into your original site's
     assets/ folder (just add the files — don't delete anything yet).
  4. Copy every {VIN} folder into your original site folder too, overwriting
     any folders with the same name.
  5. Re-upload: drag your original (now updated) folder onto your host's
     deploy area again, or push it through GitHub Desktop as usual.

KEEP THE FOLDER STRUCTURE. index.html looks for assets/ files next to itself.
